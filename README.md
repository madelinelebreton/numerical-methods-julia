# Numerical Methods in Julia

Coursework from *MECHTRON 3X03: Scientific Computation* at McMaster University (Fall 2025) — implementing core numerical methods from scratch in Julia, without relying on built-in solvers.

## Contents

| Project | Topics |
|---|---|
| [Assignment 1 — Linear Systems](./assignment-1-linear-systems) | Floating-point error analysis, backward substitution, Gaussian elimination, partial pivoting, conditioning |
| [Assignment 2 — Eigenvalues & Optimization](./assignment-2-eigenvalues-optimization) | Power method, Newton's method (root-finding & multivariate), SVD, least squares |
| [Assignment 3 — Interpolation & Integration](./assignment-3-interpolation-integration) | Newton divided-difference interpolation, composite and adaptive numerical integration |

## Skills demonstrated

- Numerical stability, floating-point error, and conditioning analysis
- Direct and iterative linear algebra solvers implemented from first principles
- Root-finding and unconstrained optimization (Newton's method, gradient methods)
- Interpolation and numerical integration schemes
- Julia for scientific computing, including error benchmarking and visualization

Each assignment folder contains the Julia implementation and a write-up (PDF) with derivations, error analysis, and plots.
